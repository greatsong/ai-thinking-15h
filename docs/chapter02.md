# 2회차: 문제를 쪼개는 기술

> **소속 계층**: Layer 1 — 구조적 사고력 ("어떻게 생각할 것인가")
> **회차**: 2/10 (90분)
> **선수 학습**: 1회차에서 CT 4요소(분해, 패턴 인식, 추상화, 알고리즘 설계)를 개괄적으로 학습한 상태
> **핵심 CT 요소**: 분해(Decomposition) 심화
> **AI 도구 사용**: 없음 (Layer 1)

---

## 학습 목표

이 회차를 마치면 학습자는 다음을 할 수 있습니다.

1. **분해(Decomposition)의 원리를 설명하고 적용할 수 있다**
   - 큰 문제를 더 작고 다루기 쉬운 하위 문제로 나누는 이유와 방법을 자기 말로 설명합니다.

2. **MECE 원칙의 의미를 이해하고 분해의 품질을 점검할 수 있다**
   - 상호 배타적(Mutually Exclusive): 하위 문제끼리 겹치지 않는가?
   - 전체 포괄적(Collectively Exhaustive): 빠뜨린 것은 없는가?
   - 이 두 기준으로 자신과 타인의 분해를 검증합니다.

3. **실제 문제를 하위 문제로 분해하는 설계서를 작성할 수 있다**
   - 시험 준비, 진로 탐색, 동아리 기획 등 학교생활의 문제를 선택하여 "문제 분해 설계서"를 완성합니다.

> **Bloom's Taxonomy 수준**: 분석(Analyze) — 정보를 부분으로 나누고 관계를 파악한다.

## 도입 (10분) — "왜 이것이 필요한가?"

### 1회차 복습 (3분)

#### 진행 스크립트

> "지난 시간에 우리는 AI 시대에 남는 능력이 무엇인지 이야기했습니다. 기억나시나요? 코드를 쓰는 능력, 번역하는 능력, 그림을 그리는 능력 — 이런 '실행 능력'은 AI가 빠르게 따라잡고 있습니다. 그 대신 우리에게 남는 것은 **문제를 정의하고, 구조화하는 힘** — Computational Thinking이었습니다."

> "CT의 4요소를 떠올려 봅시다. 누가 하나씩 말해줄 수 있나요?"

#### 빠른 확인 질문

칠판이나 화면에 4개의 칸을 만들고, 학생들이 채우도록 합니다.

```
+------------------+------------------+
| 1. ________      | 2. ________      |
| (큰 문제를       | (반복되는        |
|  작게 나누기)    |  규칙 찾기)      |
+------------------+------------------+
| 3. ________      | 4. ________      |
| (핵심만          | (절차를          |
|  남기기)         |  설계하기)       |
+------------------+------------------+

정답: 1. 분해  2. 패턴 인식  3. 추상화  4. 알고리즘 설계
```

**진행자 팁**: 학생들이 정확한 용어를 기억하지 못해도 괜찮습니다. "큰 거 쪼개는 거요", "규칙 찾는 거요"처럼 자기 말로 대답하면 충분합니다. 오히려 자기 말로 표현하는 것이 더 좋은 학습 증거입니다.

### 오늘의 문제 제기 (7분)

#### 진행 스크립트 — "기말고사의 공포"

> "자, 오늘은 CT 4요소 중 첫 번째, **분해(Decomposition)**를 깊이 파고들어 보겠습니다. 먼저 하나 여쭤볼게요."

> "기말고사 2주 전입니다. 시험 범위는 국어, 수학, 영어, 사회, 과학, 한국사... 최소 6과목. 한 과목당 3~5개 단원. 문제 유형도 객관식, 서술형, 논술형... 이걸 보면 어떤 느낌이 드나요?"

(학생 반응을 기다린다.)

> "**막막하다.** 맞습니다. 그런데 왜 막막할까요? 공부를 안 해서? 그것도 있겠지만, 더 본질적인 이유가 있습니다. **문제가 너무 크기 때문**입니다."

#### 비유: 피자 한 판

> "피자를 떠올려 봅시다. 피자 한 판이 통째로 나오면 어떻게 하나요? 그대로 들고 먹을 수 있나요? 아닙니다. **조각으로 잘라야** 먹을 수 있습니다. 크기가 작아지면 갑자기 다루기 쉬워지죠."

> "공부도 마찬가지입니다. '기말고사 준비'라는 피자 한 판을 그대로 바라보면 막막합니다. 하지만 이렇게 자르면 어떨까요?"

```
기말고사 준비 (피자 한 판)
  ├── 국어 (한 조각)
  │     ├── 문학 — 현대시 3편 분석
  │     ├── 독서 — 비문학 독해 유형 연습
  │     └── 문법 — 음운 변동 규칙 정리
  ├── 수학 (한 조각)
  │     ├── 수열 — 공식 암기 + 응용 문제 5개
  │     ├── 함수 — 그래프 해석 연습
  │     └── 확률 — 경우의 수 문제 풀이
  ├── 영어 (한 조각)
  │     └── ...
  └── ... (나머지 과목)
```

> "갑자기 보이지 않나요? '오늘은 국어 문학 현대시 3편만 하자' — 이렇게 되면 **당장 오늘 할 일**이 구체적으로 보입니다. 이것이 **분해의 힘**입니다."

**진행자 팁**: 기말고사는 대부분의 학생이 공감하는 주제입니다. "막막하다"는 감정에 공감하면서, 그 원인이 '게으름'이 아니라 '문제의 크기'에 있다는 관점 전환이 이 도입의 핵심입니다. 학생들이 "아, 그래서 막막했구나"라고 느끼면 성공입니다.

## 탐색 (15분) — "먼저 생각해보자"

### 활동 1: 개인 탐색 (5분)

각자 종이나 메모장에 다음 질문에 답을 작성합니다.

> **질문**: "학교생활에서 '복잡하다', '막막하다'고 느꼈던 문제를 3가지 적어보세요. 그리고 각각 **왜 복잡하게 느껴졌는지** 한 줄로 이유를 적어보세요."

#### 작성 예시

| 복잡했던 문제 | 왜 복잡했나? |
|--------------|-------------|
| 학교 축제 부스 기획 | 해야 할 일이 너무 많아서 뭐부터 할지 모르겠다 |
| 수학여행 자유시간 계획 | 가고 싶은 곳은 많은데 시간은 한정되어 있다 |
| 과학 탐구 보고서 작성 | 무슨 내용을 넣어야 하는지 기준을 모르겠다 |

**진행자 팁**: 학생들이 "별로 없는데요"라고 하면, 다음 보조 질문을 던져주세요.
- "동아리에서 뭔가 준비한 적 있나요?"
- "발표 자료 만들 때 막막했던 적은요?"
- "여행이나 모임을 계획해본 적은요?"

---

### 활동 2: 모둠 토론 (10분)

4인 1조로 모여 각자 적은 것을 공유합니다. 그 후 함께 다음을 분석합니다.

#### 토론 가이드

> **모둠 과제**: 모둠원들이 적은 "복잡한 문제"들을 모아놓고, 다음 질문에 답해보세요.

1. **"이 문제들의 공통점은 무엇인가요?"**
   - 왜 복잡하다고 느꼈는지의 이유들을 비교해 보세요.

2. **"복잡한 문제를 풀 때 여러분은 보통 어떻게 하나요?"**
   - 전략이 있었나요, 아니면 그냥 닥치는 대로 했나요?

3. **"만약 그 문제를 작은 조각으로 나눌 수 있었다면, 덜 막막했을까요?"**

#### 진행자가 유도할 방향

학생들이 자연스럽게 도달하기를 기대하는 키워드들:

- "할 일이 너무 많아서" → **크기의 문제** (문제가 크다)
- "뭐부터 해야 할지 몰라서" → **구조의 문제** (나눠지지 않았다)
- "기준을 모르겠어서" → **분류 기준의 문제** (어떻게 나눌지 모른다)

> **진행자가 토론 후 정리하며 말할 내용**:
> "여러분이 지금 발견한 것이 매우 중요합니다. 복잡한 문제가 막막한 이유는 대부분 **문제가 크고, 나눠지지 않았기 때문**입니다. 반대로 말하면, **잘 나누기만 하면 갑자기 다룰 수 있게 된다**는 뜻이기도 합니다. 그렇다면 질문은 이것입니다 — **잘 나눈다는 건 무엇일까요?**"

**진행자 팁**: 토론이 침묵으로 빠질 때 활용할 수 있는 보조 질문들:
- "혹시 계획을 세워서 잘 해결한 경험이 있나요? 그때 어떻게 했나요?"
- "게임에서 큰 퀘스트를 할 때, 보통 어떻게 진행하나요? 한 번에 다 하나요?"
- "요리할 때 레시피를 보면, 단계별로 나눠져 있잖아요. 왜 그렇게 되어 있을까요?"

## 핵심 개념 (15분) — "이런 관점이 있다"

### 탐색 결과와의 연결

> "여러분이 토론에서 발견한 것 — '문제가 크면 막막하고, 나누면 다룰 수 있게 된다' — 이것을 컴퓨팅 사고(CT)에서는 **분해(Decomposition)**라고 부릅니다. 1회차에서 잠깐 소개했었는데, 오늘은 이것을 제대로 파고들어 보겠습니다."

---

### 분해(Decomposition)란?

> **정의**: 크고 복잡한 문제를 더 작고, 다루기 쉬운 하위 문제(sub-problem)로 나누는 것

#### 왜 분해가 중요한가?

```
분해하지 않았을 때              분해했을 때
+---------------------+        +---------------------+
|                     |        | [하위 1] ✓ 완료     |
|   거대한 문제        |        | [하위 2] ■ 진행 중  |
|   → 어디서부터?     |   →    | [하위 3] □ 대기     |
|   → 뭘 해야 하지?   |        | [하위 4] □ 대기     |
|   → 막막...         |        | [하위 5] □ 대기     |
|                     |        |                     |
+---------------------+        +---------------------+
  감정: 불안, 회피               감정: 통제감, 진행감
```

분해의 효과를 정리하면:

| 분해 전 | 분해 후 |
|---------|---------|
| 문제가 막연하다 | 각 조각이 구체적이다 |
| 어디서 시작할지 모른다 | 첫 번째 조각부터 시작하면 된다 |
| 진행 상황을 알 수 없다 | 몇 개 완료했는지 바로 보인다 |
| 혼자 다 해야 할 것 같다 | 조각별로 역할을 나눌 수 있다 |
| 실패하면 전부 실패 | 한 조각이 실패해도 나머지는 괜찮다 |

---

### 좋은 분해 vs 나쁜 분해

> "그런데 아무렇게나 나눈다고 좋은 건 아닙니다. 분해에도 **좋은 분해**와 **나쁜 분해**가 있습니다."

#### 사례: "학교 축제 준비"를 분해해보기

**나쁜 분해 (예시 A)**:

```
학교 축제 준비
  ├── 재미있는 것 하기
  ├── 준비물 사기
  └── 열심히 하기
```

> 문제점: "재미있는 것 하기"와 "열심히 하기"는 범위가 모호합니다. 무엇이 빠졌는지도 알 수 없고, 겹치는 부분도 있을 수 있습니다.

**좋은 분해 (예시 B)**:

```
학교 축제 준비
  ├── 1. 콘텐츠 기획: 부스에서 무엇을 할 것인가?
  │     ├── 부스 주제 선정
  │     ├── 체험 활동 설계
  │     └── 필요한 재료 목록 작성
  ├── 2. 공간과 물자: 어디서, 무엇으로 할 것인가?
  │     ├── 부스 위치 신청
  │     ├── 필요 물품 구매/대여
  │     └── 부스 장식 계획
  ├── 3. 인력과 역할: 누가 무엇을 할 것인가?
  │     ├── 역할 분담 (진행, 안내, 정리)
  │     ├── 시간대별 교대 계획
  │     └── 비상 시 대처 담당
  └── 4. 홍보와 운영: 어떻게 알리고 운영할 것인가?
        ├── 포스터/SNS 홍보
        ├── 당일 운영 매뉴얼
        └── 정리 및 뒷정리 계획
```

> "예시 B가 훨씬 낫다는 것이 느껴지시나요? 왜 그럴까요? 예시 B는 **빠진 것이 없고, 겹치는 것도 없습니다**. 이것을 전문 용어로 **MECE**라고 합니다."

**진행자 팁**: 이 비교를 보여줄 때, 학생들에게 먼저 "예시 A의 문제점이 뭘까요?"라고 질문한 뒤 2~3명의 답변을 받고 나서 설명으로 넘어갑니다. 학생들이 스스로 문제점을 발견하게 하는 것이 더 효과적입니다.

---

### MECE 원칙

> **MECE** (미시, Mutually Exclusive & Collectively Exhaustive)
> - **Mutually Exclusive (상호 배타적)**: 각 조각이 서로 겹치지 않는다
> - **Collectively Exhaustive (전체 포괄적)**: 모든 조각을 합치면 원래 문제 전체를 빠짐없이 덮는다

#### MECE를 쉽게 이해하는 비유

> "퍼즐을 생각해 보세요. 좋은 퍼즐은 어떤가요?"
> - 조각이 겹치면? → 맞출 수가 없습니다 (ME 위반)
> - 조각이 빠지면? → 그림이 완성되지 않습니다 (CE 위반)
> - 겹치지도 않고, 빠지지도 않으면? → 완벽한 퍼즐 = **MECE**

```
+-------+-------+-------+
|       |       |       |
|   1   |   2   |   3   |
|       |       |       |
+-------+-------+-------+    ← MECE: 겹침 없음, 빠짐 없음
|       |       |       |
|   4   |   5   |   6   |
|       |       |       |
+-------+-------+-------+
```

```
+-------+---+---+-------+
|       | 겹|침 |       |
|   1   +---+   |   3   |
|       |   2   |       |
+-------+-------+-------+    ← ME 위반: 1과 2가 겹침
|       |       |
|   4   |   5   |  ← CE 위반: 6이 빠짐
|       |       |
+-------+-------+
```

#### MECE 점검 연습: 학교생활 사례

**연습 1: 시험 준비를 분해해봅시다**

> "기말고사 준비를 교과별로 분해하면 MECE일까요?"

| 분해 | ME (겹침 없음?) | CE (빠짐 없음?) | MECE? |
|------|----------------|----------------|-------|
| 국어, 수학, 영어, 과학, 사회, 한국사 | 과목별로 겹치지 않음 | 모든 시험 과목 포함 | MECE |
| 암기 과목, 이해 과목, 실기 과목 | 수학은 암기? 이해? 겹칠 수 있음 | 포함은 될 수 있음 | ME 위반 가능 |
| 잘하는 과목, 못하는 과목 | 겹치지 않음 | "보통인 과목"이 빠질 수 있음 | CE 위반 가능 |

> "보이시나요? 같은 '시험 준비'를 분해하더라도, **어떤 기준으로 나누느냐**에 따라 MECE가 되기도 하고 안 되기도 합니다. 분해 기준을 잘 선택하는 것이 핵심입니다."

**연습 2: 동아리 신설 계획을 분해해봅시다**

> "동아리를 새로 만들고 싶다면, 어떤 하위 문제로 나눌 수 있을까요?"

(학생 2~3명의 답변을 받은 후 정리)

```
동아리 신설 계획
  ├── 무엇을 할 것인가? (활동 내용)
  ├── 누구와 할 것인가? (구성원 모집)
  ├── 어디서 할 것인가? (장소 확보)
  ├── 언제 할 것인가? (활동 일정)
  └── 어떻게 공식화할 것인가? (학교 승인 절차)
```

> "이 분해는 '무엇-누구-어디-언제-어떻게'라는 기준으로 나누었습니다. 5W1H라고 하죠. 이렇게 나누면 자연스럽게 MECE에 가까워집니다."

**진행자 팁**: MECE라는 용어를 학생들이 부담스러워할 수 있습니다. "쉽게 말하면, 빠진 거 없나? 겹치는 거 없나? 이 두 가지만 확인하면 됩니다"라고 간결하게 풀어주세요. 용어 자체보다 **점검하는 습관**이 중요합니다.

### 분해의 깊이: 언제 멈출 것인가?

> "분해를 계속하면 끝없이 쪼갤 수 있습니다. 그렇다면 언제 멈춰야 할까요?"

#### 멈추는 기준

> **"이 조각을 보고 당장 행동에 옮길 수 있는가?"**

```
수준 1 (너무 큼):     "수학 공부하기"         → 아직 막막하다
수준 2 (적절함):      "수열 단원 공식 정리"    → 행동에 옮길 수 있다
수준 3 (너무 작음):   "수열 공식 3번째 줄 암기" → 지나치게 잘게 쪼갰다
```

> "적절한 깊이는 **'이걸 보면 바로 시작할 수 있다'**고 느끼는 수준입니다. 사람마다, 상황마다 그 수준은 다를 수 있습니다. 정답은 없지만, 기준은 있습니다."

**진행자 팁**: 학생들에게 "너무 크다"와 "너무 작다"의 경계를 스스로 찾게 하는 것이 좋습니다. "여러분 각자에게 '이 정도면 바로 할 수 있겠다'는 크기가 다를 수 있어요. 그게 정상입니다."

### 문제 예시 (선택이 어려운 학생을 위해)

### 실습 중 순회 가이드 (진행자용)

실습 중 교실을 순회하면서 다음과 같은 상황에 대처합니다.

#### 상황 1: "뭘 고를지 모르겠어요"

> **대처**: "지금 당장 고민인 것 있나요? 작은 것이라도 괜찮아요. 시험 준비도 되고, 이번 주말 약속 잡는 것도 됩니다."

#### 상황 2: "2개밖에 안 나와요"

> **대처**: "2개도 좋은 시작입니다. 그 2개가 전부인지 점검해 보세요. 혹시 빠진 것이 없나요? CE 점검이죠."

#### 상황 3: "10개나 나왔어요"

> **대처**: "대단하네요! 그런데 10개 중에 겹치는 것이 있지 않나요? 비슷한 것끼리 묶어볼 수 있을까요? ME 점검이에요."

#### 상황 4: "이게 맞는지 모르겠어요"

> **대처**: "정답은 없습니다. 중요한 것은 '왜 이렇게 나누었는지'를 설명할 수 있느냐입니다. 옆 친구에게 설명해 보세요. 설명이 되면 좋은 분해입니다."

#### 상황 5: "분해 기준을 뭘로 해야 하나요?"

> **대처**: "같은 문제도 여러 기준으로 나눌 수 있어요. 시간 순서로 나눌 수도 있고, 종류별로 나눌 수도 있습니다. 어떤 기준으로 나누면 '행동에 옮기기 쉬운지' 생각해 보세요."

### 작성 예시 (교사 참고용 — 학생에게 배포하지 않음)

다음은 "기말고사 2주 준비"를 분해한 예시입니다. 학생들이 실습 중에 막힐 때 구두로 힌트를 줄 수 있습니다.

```

   복잡한 이유:
   (1) 과목 수가 많아서 시간 배분이 어렵다
   (2) 과목마다 공부 방법이 달라서 혼란스럽다
   (3) 어떤 과목부터 해야 할지 우선순위를 모르겠다

   이유: 시험이 과목별로 치러지므로, 과목별로 나누면 각 과목에
         필요한 준비를 구체적으로 파악할 수 있다.

[3단계] 하위 문제:

   2. 수학: 수열 공식 정리 + 함수 그래프 문제 + 확률 응용 문제

[4단계] MECE 점검:
   ME: 과목별이므로 겹치지 않음 ✓
   CE: 6과목 모두 포함됨 ✓ (체육, 음악 등 실기 과목은 포함했는가?)

[5단계] 시각화:
              [기말고사 2주 준비]
          /    |     |     |      \
       국어  수학  영어  과학  사회/한국사
       /|\   /|\   /|\
    시 독 문 수 함 확 단 독 서
    분 해 법 열 수 률 어 해 술
    석         그
              래
              프

|  E. 한 줄 피드백                                                |
|                                                                |
|  잘한 점: _________________________________________________    |
|                                                                |
|  개선할 점: _______________________________________________    |
|                                                                |
+================================================================+
```

#### 단계 3: 피드백 공유 및 토론 (5분)

> "피드백을 받은 후, 원래 모둠으로 돌아와서 이야기해 봅시다."

모둠 내 토론 질문:
- "피드백에서 가장 인상적이었던 점은 무엇인가요?"
- "빠진 부분이나 겹치는 부분을 발견했나요?"
- "분해 기준에 대한 대안이 나왔나요? 그것이 더 나을까요?"

#### 단계 4: 전체 공유 (2분)

시간이 허용되면 1~2개 사례를 전체에 공유합니다. 진행자가 질문합니다:

> "이 분해에서 가장 잘된 부분은 무엇인가요?"
> "MECE 관점에서 보완할 점이 있다면요?"

**진행자 팁**:
- 피드백 과정에서 "틀렸다"는 표현은 지양합니다. "빠진 것이 있을 수 있다", "다른 기준도 가능하다"처럼 건설적으로 유도합니다.
- 학생들이 서로의 설계서를 볼 때, "다른 사람은 이렇게 나누었구나"라는 발견 자체가 학습입니다. 같은 문제를 다르게 분해할 수 있다는 것을 경험하는 것이 중요합니다.
- 피드백을 주는 것 자체가 MECE 점검 연습입니다. "빠진 게 뭐지?", "겹치는 게 뭐지?"를 반복적으로 생각하게 됩니다.

## 정리 (5분) — "오늘의 핵심"

### 핵심 한 줄 요약

> **"큰 문제는 쪼개면 작아지고, 작아지면 해결할 수 있게 됩니다. 좋은 분해란, 빠진 것 없이(CE), 겹치는 것 없이(ME) 나누는 것입니다."**

---

### 오늘의 키워드 정리

| 키워드 | 의미 | 한 줄 기억법 |
|--------|------|-------------|
| 분해 (Decomposition) | 큰 문제를 작은 하위 문제로 나누는 것 | "피자를 조각내야 먹을 수 있다" |
| MECE | 겹치지 않고(ME), 빠지지 않게(CE) 나누는 원칙 | "퍼즐 조각처럼" |
| 분해 기준 | 무엇을 기준으로 나눌 것인가 | "같은 피자도 6조각, 8조각 다르다" |
| 분해의 깊이 | 어디까지 쪼갤 것인가 | "바로 행동할 수 있는 크기면 충분" |

---

### 자기 점검 질문

수업을 마치기 전, 학생들에게 다음 3가지 질문에 스스로 답해보도록 합니다 (손가락 1~5로 자기 평가).

> 1. "분해가 무엇인지 친구에게 설명할 수 있나요?" (1: 어렵다 ~ 5: 자신 있다)
> 2. "MECE가 무엇인지 알고, 점검할 수 있나요?" (1: 어렵다 ~ 5: 자신 있다)
> 3. "실제 문제를 하위 문제로 나눠본 경험이 도움이 되었나요?" (1: 아니다 ~ 5: 매우 그렇다)

**진행자 팁**: 손가락 평가는 빠르고 부담이 없습니다. 전체적인 분위기를 파악하는 데 좋습니다. 1~2를 든 학생이 많으면, 3회차 시작 시 2회차 내용을 간단히 복습하는 시간을 조금 더 배정합니다.

---

### 3회차와의 연결

> "오늘 우리는 문제를 **쪼개는 기술**을 배웠습니다. 그런데 한 가지 더 생각해 볼 것이 있습니다. 여러분이 오늘 분해한 문제들을 보세요. 혹시 **다른 사람이 분해한 문제와 구조가 비슷한 것**이 있지 않았나요?"

> "축제 준비와 여행 계획이 비슷하다? 시험 준비와 자기 관리가 비슷하다? 이렇게 **서로 다른 문제에서 같은 구조를 발견**하는 것 — 이것을 **패턴 인식(Pattern Recognition)**이라고 합니다. 다음 시간에는 이 패턴을 찾고, 핵심만 뽑아내는 **추상화(Abstraction)**까지 함께 배워보겠습니다."

---

### 과제 (선택)

> 이번 주 안에, 일상에서 "이건 쪼개면 쉬워질 텐데"라는 순간을 **1번** 포착하고, 실제로 3개 이하의 하위 문제로 분해해 보세요. 다음 시간 시작에 1~2분 공유하겠습니다.

### B. 학생 예상 반응 및 대처법

| 예상 반응 | 대처법 |
|----------|--------|
| "이거 그냥 계획 세우는 거 아닌가요?" | "맞습니다! 계획 세우기의 핵심이 바로 분해입니다. 다만 오늘은 '잘 나누는 기준(MECE)'을 의식적으로 배우는 것이 차이입니다." |
| "MECE가 너무 어려운 용어예요" | "겹치는 거 없나? 빠진 거 없나? 이 두 질문만 기억하면 됩니다. MECE는 그냥 이름입니다." |
| "정답이 뭔가요?" | "정답은 없습니다. 같은 문제도 사람마다 다른 기준으로 나눌 수 있고, 그것이 정상입니다. 중요한 것은 '왜 그렇게 나누었는가'를 설명할 수 있느냐입니다." |
| "이미 다 아는 내용인데요" | "좋습니다! 그러면 여러분의 분해가 정말 MECE인지 점검해 보세요. 빠진 것 없이, 겹치는 것 없이 나눌 수 있나요? 의식적으로 점검하는 것과 직감적으로 하는 것은 다릅니다." |
| "실생활에서 이걸 언제 써요?" | "시험 공부 계획을 세울 때, 발표 자료를 구성할 때, 동아리 프로젝트를 기획할 때 — 이미 쓰고 있을 수 있어요. 오늘 배운 것은 그것을 '의식적으로, 잘' 하는 방법입니다." |
| "AI가 알아서 분해해주면 되는 거 아닌가요?" | "좋은 질문입니다! AI도 분해를 도와줄 수 있습니다. 하지만 AI가 분해한 결과가 맞는지 '검증'하려면 여러분이 MECE를 알아야 합니다. 5회차부터 AI를 직접 써볼 때 이 힘이 발휘됩니다." |

### D. 3회차 연결을 위한 복선

2회차에서 3회차(패턴 찾기와 핵심 추출)로의 자연스러운 전환을 위해, 다음 장치를 미리 심어둡니다.

1. **공유 시간에**: 서로 다른 문제의 분해를 비교할 때, "구조가 비슷하지 않나요?"라는 질문을 자연스럽게 던집니다.
2. **정리 시간에**: "다른 사람의 분해와 내 분해가 닮아 있다면, 그것이 패턴입니다"라고 연결합니다.
3. **과제에서**: 분해한 결과를 가져오면, 3회차 시작 시 여러 학생의 분해를 나란히 놓고 "공통 구조"를 찾는 활동으로 바로 이어갈 수 있습니다.

### E. 평가 기준 (과정 중심)

이 회차의 평가는 결과물의 완성도가 아니라 **사고의 구조화 과정**에 초점을 맞춥니다.

| 평가 항목 | 상 | 중 | 하 |
|----------|----|----|-----|
| 문제 정의 | 한 문장으로 명확하게 정의함 | 문제가 정의되었으나 범위가 모호함 | 문제 정의가 불분명함 |
| 분해 기준 | 기준을 명시하고 이유를 설명함 | 기준은 있으나 이유가 불분명함 | 기준 없이 나열함 |
| MECE 점검 | 자기 점검을 수행하고 수정함 | 점검을 시도했으나 미완성 | 점검을 하지 않음 |
| 피드백 참여 | 구체적 피드백을 제공하고 수용함 | 피드백을 제공하거나 수용함 | 피드백에 참여하지 않음 |
| 분해의 깊이 | 행동에 옮길 수 있는 수준으로 분해함 | 분해했으나 일부 조각이 너무 크거나 작음 | 분해가 피상적임 |

## 이 회차의 설계 의도 요약

| 설계 원칙 | 이 회차에서의 적용 |
|----------|------------------|
| "체험 먼저, 개념 나중" | 기말고사 막막함을 먼저 체감 → 분해/MECE 개념으로 정리 |
| "만들라고 하지 말고, 생각해보라고 시켜라" | 정답을 주지 않고, 학생이 직접 분해 기준을 선택하게 함 |
| "결과물이 아니라 과정" | 분해 결과의 정확성이 아니라, 분해하는 과정(기준 선택, MECE 점검)을 평가 |
| "또래 학습" | 모둠 토론(탐색), 피어 리뷰(공유와 검증)로 상호 학습 |
| "다음 회차 연결" | 패턴 인식으로의 복선을 정리 시간에 배치 |

> **핵심**: 이 회차가 끝나면 학생들은 "복잡한 문제를 보면 일단 쪼개본다"는 습관과, "잘 쪼갰는지 확인한다(MECE)"는 점검 기준을 갖추게 됩니다. 이것이 3회차(패턴 인식)와 4회차(알고리즘 설계)의 토대가 됩니다.
