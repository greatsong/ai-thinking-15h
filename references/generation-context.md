# 챕터 생성 컨텍스트 — AI 시대의 구조적 사고 (15시간 과정)

## 1. 과정 정보

- **과정명**: AI 시대의 구조적 사고 — 생각하는 힘 키우기
- **대상**: 고등학교 1~2학년 (AI 입문자, 프로그래밍 경험 불필요)
- **형식**: 10회 × 90분 = 15시간
- **구조**: Layer 1(4회) → Layer 2(4회) → Layer 3(2회)

## 2. 교육 철학 (절대 원칙)

1. **"만들라고 하지 말고, 생각해보라고 시켜라"**
   - 결과물을 직접 요청하지 않는다
   - 선택지를 제안하고, 학습자가 선택한다
   - 점진적 대화로 사고의 깊이를 쌓는다

2. **"결과물이 아니라 생성 장치(Harness)를 만들어라"**
   - 보고서 하나를 쓰는 게 아니라
   - 보고서를 반복적으로 만들어내는 '기준과 구조'를 설계한다

3. **"코드가 아니라 로직을 가르쳐라"**
   - 특정 도구 사용법 나열 금지 (도구는 바뀌므로)
   - 문제 정의 → 분해 → 구조화 → 검증의 사고 과정을 가르친다

4. **"체험 먼저, 개념 나중"**
   - 귀납적 접근: 학습자가 먼저 경험하고, 이후 프레임워크로 정리한다
   - 답을 가르치지 않고 질문으로 유도한다

## 3. 회차별 구조 (90분 기준)

모든 챕터는 다음 구조를 따른다:

| 단계 | 시간 | 목적 |
|------|------|------|
| 도입 | 10분 | "왜 이것이 필요한가?" — 사례/비유로 필요성 체감 |
| 탐색 | 15분 | "먼저 생각해보자" — 개인 탐색 + 모둠 토론 |
| 핵심 개념 | 15분 | "이런 관점이 있다" — 탐색 결과를 프레임워크로 연결 |
| 실습 | 30분 | "구조를 설계해보자" — 워크시트 기반 설계 활동 |
| 공유와 검증 | 15분 | "서로의 설계를 검증하자" — 모둠 간 교환 피드백 |
| 정리 | 5분 | "오늘의 핵심" — 한 줄 요약 + 다음 회차 연결 |

## 4. 3계층 구조

```
Layer 1: 구조적 사고력 (1~4회차)
  → Computational Thinking의 4요소
  → AI 없이 '생각하는 힘' 자체를 훈련
  → Bloom's: 분석(Analyze) 수준까지

Layer 2: AI 협업 설계력 (5~8회차)
  → AI 활용 3단계, 설계서 작성, 탐색적 대화
  → AI를 도구로 사용하되, 사고의 주도권은 학습자가 유지
  → Bloom's: 평가(Evaluate) 수준까지

Layer 3: 분야 융합 적용력 (9~10회차)
  → 자기 관심 분야에서 AI 활용점 탐색
  → 미니 프로젝트 설계 및 발표
  → Bloom's: 창조(Create) 수준까지
```

## 5. 대상 특성 (고등학교 1~2학년)

### 고려사항
- AI 도구를 처음 접하거나 '숙제 대행용'으로만 사용해본 수준
- 추상적 개념보다 구체적 체험이 효과적
- 학교생활, 시험, 동아리, 진로 등의 맥락이 공감도 높음
- 모둠 활동과 또래 학습이 효과적
- Layer 3에서 '도메인'이 직업이 아닌 교과/관심사/학교생활

### 사례 선택 기준
- **우선**: 학교생활 (시험 준비, 발표, 독서감상문, 동아리, 축제)
- **보조**: 일상생활 (여행 계획, 요리, 게임 전략, 운동 루틴)
- **지양**: 전문 직업 맥락 (의료, 법률, 금융 등은 간략히만)

### 어투와 스타일
- 반말(~다/~이다) 대신 존댓말(~합니다/~입니다) 사용
- 경어 체 사용하되 딱딱하지 않게
- 학생에게 직접 말하는 듯한 톤
- 이모지 사용 자제, 필요 시 최소한으로

## 6. 워크시트 설계 원칙

- 매 회차 실습에 구체적인 워크시트(A4 기준) 포함
- 빈칸 채우기 형식으로 부담 낮게
- 단계별 안내(몇 분, 무엇을 하는지) 명시
- 검증 체크리스트 포함 (자기 검증 + 또래 검증)

## 7. 평가 원칙

- 결과물의 완성도가 아니라 **사고의 구조화 과정**을 평가
- 매 회차 자기 평가 + 또래 피드백
- 최종 프로젝트는 과정(설계서의 논리성)에 가중치

## 8. 진행자 팁 포함 규칙

매 단계마다 "진행자 팁"을 포함한다:
- 학생의 예상 반응과 대처법
- "정답이 없습니다"를 강조하는 시점
- 시간 조절 방법
- 토론이 침묵으로 빠질 때의 보조 질문
