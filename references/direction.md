# 문제 1 확정: 교육 방향성

> 선택일: 2026-02-21
> 선택: **D — 세 가지 전환 통합**

## 확정된 방향

AI 시대 교육은 세 가지 전환을 **계층 구조**로 통합한다:

```
Layer 1 (기초):  로직 퍼스트
                 → 코드가 아니라 "문제를 구조화하는 사고"를 가르친다

Layer 2 (실천):  Harness 설계
                 → 결과물이 아니라 "결과물을 만드는 장치"를 설계하는 법을 가르친다

Layer 3 (응용):  IT + Something
                 → 자기 도메인에서 AI를 활용해 가치를 만드는 법을 가르친다
```

## 이 방향이 EP86의 철학과 연결되는 지점

| 계층 | EP86 핵심 메시지 | 교육에서의 구현 |
|------|-----------------|----------------|
| Layer 1 | "컴퓨터 공학은 로직을 세우는 방법론" | 문제 정의 → 분해 → 구조화 훈련 |
| Layer 2 | "만들지 말고 생각하게 하라" | CLAUDE.md 작성, 프롬프트 설계, 워크플로우 구축 |
| Layer 3 | "IT + Something이 경쟁력" | 각자의 분야에서 AI 활용 프로젝트 |

## 운영 원칙

1. **단계별 심화**: Layer 1 → 2 → 3 순서로 진행 (건너뛰지 않음)
2. **대상별 강조점 조절**: 초보자는 Layer 1 비중 높게, 숙련자는 Layer 3 비중 높게
3. **도구 비의존**: 특정 AI 도구에 묶이지 않는 보편적 원리 중심
4. **과정 평가**: 결과물이 아니라 구조화 과정을 평가

## 이 방향성이 문제 2에 주는 제약 조건

- 커리큘럼은 반드시 3개 Layer를 모두 포함해야 함
- 각 모듈은 "만들어봐"가 아니라 "생각해봐"로 시작해야 함
- 실습은 반드시 Harness 설계를 포함해야 함
- 특정 도구 매뉴얼이 되어서는 안 됨
