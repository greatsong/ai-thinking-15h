    10회차: AI와 나의 미래¶

    과정: AI 시대의 구조적 사고 — 생각하는 힘 키우기 계층: Layer 3 — 분야 융합 적용력 (과정 마무리) 회차: 10/10 (90분) — 최종 회차 대상: 고등학교 1~2학년 (AI 입문자, 프로그래밍 경험 불필요) AI 도구 사용: 발표에서 AI 활용 결과를 공유합니다

    학습 목표¶

    이 수업을 마치면 여러분은 다음을 할 수 있습니다:

    1. Layer 1~3을 통합한 미니 프로젝트를 완성하고 그 결과와 과정을 발표할 수 있다
    2. 10회 과정 전체를 회고하며, 자신의 사고방식 변화를 메타인지적으로 성찰할 수 있다
    3. AI 시대에 자신이 키워야 할 역량과 방향을 자기 말로 표현할 수 있다

    Bloom's Taxonomy 수준: 창조(Create) — 배운 것을 종합하여 새로운 관점을 형성한다.

    수업 흐름 한눈에 보기¶

    이번 회차는 최종 회차로, 일반 회차와 다른 특별 구조로 진행됩니다.

    단계 시간 핵심 활동
    전반부: 미니 프로젝트 발표 45분
    1. 발표 안내 5분 발표 형식, 시간, 핵심 기준 안내
    2. 모둠별/개인별 발표 30분 "결과물이 아니라 과정을 발표한다"
    3. 상호 피드백 10분 피드백 카드 교환 + "가장 인상 깊었던 프로젝트" 공유
    후반부: 전체 회고 + 미래 방향 45분
    4. 10회차 여정 되돌아보기 15분 "1회차의 나 vs 10회차의 나" — 개인 성찰 워크시트
    5. "AI와 나의 미래" 열린 토론 20분 모둠 토론 → 전체 공유
    6. 마무리 10분 진행자 최종 메시지 + 수료 안내 + 포트폴리오 정리

    준비물¶

    항목 수량 비고
    발표 평가 카드 (인쇄) 인원 수 x 발표 모둠 수 본 자료의 검증 체크리스트 참조
    개인 성찰 워크시트 (인쇄) 인원 수 "1회차의 나 vs 10회차의 나"
    포트폴리오 정리 체크리스트 (인쇄) 인원 수 10회분 산출물 목록
    피드백 카드 (또는 포스트잇) 인원 수 x 2장 상호 피드백용
    타이머 (또는 스마트폰 타이머) 1 발표 시간 관리용
    1~9회차 핵심 키워드 판서용 전지 1~2장 타임라인 시각화용
    네임펜 (또는 굵은 펜) 모둠당 4개 타임라인 작성용
    수료증 (선택) 인원 수 미리 준비하면 감동 증가

    진행 스크립트¶

    "여러분, 드디어 마지막 시간입니다. 오늘은 9회차에서 설계한 미니 프로젝트를 발표하는 시간이에요. 그런데 시작하기 전에 한 가지 꼭 말씀드리고 싶은 것이 있습니다."

    (잠시 멈춤)

    "오늘 발표는 '결과물 품평회'가 아닙니다. 누가 더 멋진 결과물을 만들었는지를 겨루는 시간이 아니에요. 오늘은 '과정 공유회'입니다. 여러분이 어떤 문제를 발견했고, 어떻게 생각했고, 무엇을 배웠는지를 나누는 시간이에요. 그러니까 결과물이 완벽하지 않아도 전혀 괜찮습니다. 오히려 '이 부분에서 막혔는데 이렇게 해결했다'는 이야기가 더 값진 발표가 될 겁니다."

    발표 기본 안내¶

    항목 내용
    발표 시간 모둠당 5분 발표 + 2분 질의응답 (총 약 7분)
    발표 형식 자유 (구두 설명, 워크시트 보여주기, 화이트보드, 슬라이드 등)
    발표 인원 모둠 전원이 역할을 나눠 발표하는 것을 권장
    핵심 기준 결과물의 완성도가 아니라, 사고의 과정과 구조를 평가

    슬라이드 제안 (선택 사항)¶

    슬라이드를 사용하고 싶은 모둠을 위한 안내입니다. 필수는 아닙니다.

    슬라이드 번호 제목 내용
    1 우리가 발견한 문제 문제 정의 한 문장 + 분해 구조도
    2 AI 협업 설계서 목적-규칙-맥락 요약 + 대화 예시 캡처
    3 이 분야를 선택한 이유 가치 창출 지점 분석 결과
    4 결과와 배움 결과물 요약 + "우리가 배운 것 한 가지"

    진행자 팁: 슬라이드가 없어도 전혀 문제없습니다. 워크시트를 카메라로 찍어 화면에 띄우거나, 화이트보드에 핵심만 적어 발표해도 됩니다. 형식보다 내용이 중요하다는 것을 강조하세요. "프로젝트가 완성되지 않았어도 괜찮습니다. '여기까지 했고, 여기서 막혔다'는 것도 훌륭한 발표입니다."

    2단계: 모둠별/개인별 발표 (30분)¶

    발표 진행 안내¶

    "지금부터 발표를 시작합니다. 발표하는 모둠은 앞에 나와주시고, 나머지 분들은 청중으로서 중요한 역할이 있습니다. 발표를 듣는 동안 발표 평가 카드를 작성해 주세요. 이것은 점수를 매기는 것이 아니라, 발표자에게 드리는 선물입니다."

    발표 시간 배분 (5~6개 모둠 기준)¶

    순서 소요 시간 내용
    모둠 발표 5분 발표 구조 가이드에 따라 발표
    질의응답 2분 진행자 + 청중의 질문
    전환 30초 다음 모둠 준비

    진행자 팁: 모둠 수에 따라 시간을 조절하세요. 6개 모둠이면 모둠당 약 5분(발표 3.5분 + 질의 1.5분)으로 압축합니다. 4개 모둠이면 모둠당 7분(발표 5분 + 질의 2분)으로 여유 있게 진행합니다. 타이머를 사용하되, "시간이 다 됐습니다"보다 "마지막 한 마디로 정리해주세요"가 더 부드럽습니다.

    진행자의 질문 가이드¶

    발표 후 질의응답에서 진행자는 다음과 같은 질문으로 발표의 깊이를 끌어올립니다.

    Layer 1(구조적 사고) 관련 질문: - "이 문제를 분해할 때 가장 어려웠던 부분은 어디였나요?" - "다른 기준으로 분해했다면 결과가 달라졌을까요?" - "이 문제와 비슷한 구조를 가진 다른 문제를 떠올릴 수 있나요?"

    Layer 2(AI 협업) 관련 질문: - "AI에게 처음에 어떤 수준으로 시켰고, 나중에 어떻게 바꿨나요?" - "AI의 답변 중에 '이건 아닌데'라고 느낀 순간이 있었나요? 그때 어떻게 했나요?" - "만약 AI 없이 이 프로젝트를 했다면, 무엇이 달랐을까요?"

    Layer 3(분야 융합) 관련 질문: - "이 분야에서 AI가 가장 도움이 된 지점은 어디였나요?" - "이 시스템을 다른 분야에도 적용할 수 있을까요?" - "이 프로젝트를 계속 발전시킨다면, 다음 단계는 무엇일까요?"

    성찰 관련 질문: - "이 프로젝트를 처음부터 다시 한다면, 무엇을 다르게 하고 싶나요?" - "이 과정에서 자신에 대해 새롭게 알게 된 것이 있나요?"

    진행자 팁: 모든 모둠에 똑같은 질문을 하지 마세요. 각 발표의 특성에 맞는 질문을 골라 던지되, 비판이 아닌 호기심의 톤을 유지합니다. "왜 이렇게 했어요?"보다 "이렇게 한 이유가 궁금한데요"가 더 좋습니다. 청중 학생들에게도 질문 기회를 주세요. "혹시 궁금한 점 있는 분?"

    "자, 이제 모든 발표를 들었으니 한 가지만 여쭤볼게요. 자기 모둠 것을 제외하고, 가장 인상 깊었던 프로젝트는 무엇이었나요? 그리고 왜 인상 깊었나요?"

    개인별로 손을 들고 공유합니다. 3~5명 정도의 답변을 듣습니다.

    진행자 팁: 이 활동의 핵심은 "왜"입니다. "OO 모둠이요"로 끝나지 않게, 반드시 "어떤 점이 인상 깊었는지"를 물어보세요. 학생들이 "결과물이 예뻐서"라고 답하면 "결과물 말고, 그 모둠이 문제를 찾은 방식이나 AI와 대화한 과정 중에서 인상 깊었던 것은?"으로 방향을 잡아주세요. 같은 모둠이 반복 언급되어도 괜찮습니다. 다른 모둠에도 꼭 한 가지씩 좋은 점을 짚어주면 모든 학생이 인정받는 느낌을 받을 수 있습니다.

    • 거창할 필요 없습니다. "나는 AI를 잘 쓰는 요리사가 되고 싶다"도 좋은 답입니다.
    • 모둠원의 답이 다 달라도 괜찮습니다. 다양성이 자연스럽습니다.

    진행자 팁: 토론이 침묵으로 빠질 때를 위한 보조 질문을 준비해 두세요: - "10년 후, AI가 지금보다 100배 더 똑똑해져도 변하지 않을 것은 뭘까요?" - "여러분이 미래의 후배에게 이 과정에서 배운 것을 한 마디로 전한다면?" - "AI를 가장 잘 활용하는 사람은 어떤 사람일까요?" - "이 과정 전에는 몰랐지만, 지금은 확실히 아는 것이 있다면?"

    토론이 너무 추상적으로 흐르면 "구체적으로 어떤 상황에서?"라고 물어 초점을 잡아주세요. 반대로 너무 현실적인 이야기(취업, 성적 등)에만 머무르면 "조금 더 넓게 보면, 여러분이 살고 싶은 삶은 어떤 모습인가요?"로 시야를 넓혀주세요.

    전체 공유 (8분)¶

    각 모둠에서 1~2명이 모둠의 이야기를 공유합니다.

    "각 모둠에서 가장 인상 깊었던 이야기 하나만 전체에 공유해 주세요. '우리 모둠에서 OO이가 이런 말을 했는데...'처럼 소개해도 좋고, 본인의 생각을 직접 말해도 좋습니다."

    공유를 들으며 진행자가 해야 할 것: - 각 이야기에 진심으로 반응합니다 ("정말 좋은 관점이네요") - 서로 다른 이야기를 연결합니다 ("지금 OO이 말과 아까 OO이 말이 만나는 지점이 있는 것 같아요") - 마지막에 전체를 관통하는 메시지로 묶습니다

    "여러분의 이야기를 들으면서 한 가지 공통점을 발견했습니다. 구체적인 꿈은 다 다르지만, '나만의 관점으로 AI와 함께 문제를 해결하겠다'는 방향은 같습니다. 그것이 바로 이 과정의 핵심이었어요."

    6단계: 마무리 (10분) — "여러분은 이제 다른 사람이 되었습니다"¶

    진행자 최종 메시지 스크립트¶

    "여러분, 이제 정말 마지막입니다."

    (잠시 멈추고, 학생들과 눈을 맞춘다)

    "10주 전 1회차에서 제가 이런 질문을 던졌습니다. 'AI가 이렇게 많은 것을 대신해 준다면, 우리에게 남는 능력은 무엇일까?' 그때 여러분은 포스트잇에 이런저런 답을 적었었죠."

    "10주가 지난 지금, 그 질문에 대한 답이 조금은 선명해졌기를 바랍니다. 물론 완벽한 답은 아니어도 괜찮습니다. 우리가 함께 찾은 것은 '답' 그 자체가 아니라, '답을 찾아가는 구조'이니까요."

    (잠시 멈춤)

    "이 과정을 통해 여러분이 배운 것을 제가 세 가지로 정리해 보겠습니다."

    "첫째, 문제를 구조적으로 바라보는 눈. 막막한 문제도 쪼개면 다루기 쉬워집니다. 분해하고, 패턴을 찾고, 핵심을 추출하고, 절차를 설계하는 — 이 사고의 틀은 AI가 아무리 발전해도 여러분이 직접 해야 하는 일입니다."

    "둘째, AI와 대등하게 협업하는 방법. '숙제 도와줘'가 아니라 '이 구조에 빠진 것이 있는지 검토해줘'라고 말하는 것. '결과물 만들어줘'가 아니라 '선택지를 제안해봐'라고 말하는 것. 이것은 단순한 대화 기술이 아닙니다. 사고의 주도권을 내가 유지하면서 AI의 능력을 빌려오는 것입니다."

    "셋째, 자기 분야를 가진 사람의 힘. 기술만으로는 부족합니다. 기술과 여러분만의 관심사, 지식, 경험이 만날 때 진짜 가치가 생깁니다. 여러분이 좋아하는 것, 잘하는 것, 궁금한 것 — 그것이 바로 여러분의 Something입니다."

    (한 박자 쉬고)

    "마지막으로 하나만 더 말씀드릴게요."

    "이 과정을 시작하기 전, 여러분은 아마 AI를 '시키는 도구'로 생각했을 겁니다. '이것 좀 해줘', '저것 좀 만들어줘'라고요. 하지만 지금의 여러분은 다릅니다."

    "여러분은 이제 AI를 '시키는 사람'이 아니라, 'AI와 함께 생각하는 사람'입니다."

    "그리고 그 '함께 생각하는 능력'은 앞으로 AI가 아무리 발전해도 더 중요해질 겁니다. 왜냐하면 '무엇을 생각할지 정하는 것'은 결국 사람의 일이니까요."

    "10주 동안 수고 많으셨습니다. 여러분의 여정은 여기서 끝나는 것이 아니라, 여기서 시작됩니다. 오늘 이후에도 문제를 만나면 먼저 쪼개보세요. AI에게 물어보기 전에 먼저 생각해보세요. 그리고 여러분만의 Something을 계속 키워가세요."

    "감사합니다."

    (박수)

    진행자 팁: 이 스크립트는 참고용입니다. 자신만의 말투와 경험으로 바꾸셔도 됩니다. 중요한 것은 세 가지 핵심 메시지(구조적 사고, AI와의 대등한 협업, 자기 분야의 힘)를 전달하는 것입니다. 스크립트를 읽는 것보다 학생들의 눈을 바라보며 진심을 담아 말하는 것이 훨씬 효과적입니다. 10주 동안의 구체적인 에피소드(예: "5회차에서 OO이가 이런 질문을 했었는데, 그게 정말 인상 깊었어요")를 넣으면 감동이 배가됩니다.

    수료 안내 (3분)¶

    "이것으로 'AI 시대의 구조적 사고 — 생각하는 힘 키우기' 과정이 공식적으로 끝났습니다."

    수료증이 있다면 이 시점에서 배부합니다.

    "수료증을 받으셨지만, 진짜 수료증은 종이가 아니라 여러분의 머릿속에 있습니다. 문제를 보는 눈이 달라진 것, 그것이 진짜 수료증입니다."

    포트폴리오 정리 안내 (5분)¶

    A. 예상 질문과 답변¶

    학생 질문 권장 답변
    "발표 준비가 덜 됐는데요" "완성되지 않아도 괜찮습니다. '여기까지 했고, 여기서 막혔다'는 것도 훌륭한 발표예요. 과정을 보여주는 것이 핵심이니까요."
    "프로젝트가 실패했어요" "실패한 프로젝트야말로 가장 많이 배울 수 있는 프로젝트입니다. '왜 실패했는지'를 분석해서 발표한다면, 가장 값진 발표가 될 거예요."
    "뭐가 달라졌는지 모르겠어요" "1회차에 AI에게 '숙제 도와줘'라고 말했다면, 지금은 어떻게 말할 것 같나요? 그 차이가 이미 변화입니다."
    "앞으로 뭘 더 공부해야 하나요?" "특정 도구보다는 '문제를 구조적으로 보는 습관'을 계속 연습해보세요. 그게 어떤 도구가 나와도 통하는 기본기입니다."
    "이 과정에서 배운 게 진짜 쓸모 있나요?" "솔직한 질문이에요. 지금 당장은 느끼기 어려울 수 있습니다. 하지만 한 달 후, 발표 준비할 때 '일단 쪼개보자'라는 생각이 자동으로 떠오르면, 그때 '아, 그때 배운 거구나' 하고 느끼실 거예요."

    B. 시간 조절 가이드¶

    상황 대처법
    발표 모둠이 4개 이하일 때 모둠당 7분(발표 5분 + 질의 2분) 배정, 남은 시간은 상호 피드백을 확대
    발표 모둠이 6개 이상일 때 모둠당 5분(발표 3.5분 + 질의 1.5분)으로 압축, 질문은 모둠당 1개씩만
    발표가 예상보다 빨리 끝날 때 상호 피드백 시간을 늘리거나, "가장 인상 깊었던 프로젝트" 공유를 더 많은 학생에게
    후반부 토론이 침묵으로 빠질 때 보조 질문 투입, 또는 "옆 사람과 30초 이야기한 후 공유" 방식으로 전환
    성찰 워크시트 작성이 느릴 때 "다 못 채워도 괜찮아요. 가장 중요한 한 칸이라도 채워보세요"로 부담 낮추기
    전체적으로 시간이 부족할 때 포트폴리오 정리는 "집에서 해와도 됩니다"로 전환, 진행자 메시지에 집중
    전체적으로 시간이 남을 때 "6개월 후의 나에게 편지 쓰기" 활동 추가 (5분)

    C. 발표 순서 정하기¶

    • 자원하는 모둠부터 시작합니다 (첫 발표의 긴장감을 줄이기 위해)
    • 아무도 자원하지 않으면 진행자가 "준비가 제일 잘 된 것 같은 모둠"을 가볍게 지목하되, "편하게 시작해도 되는 모둠?"으로 재질문
    • 마지막 발표는 가장 독특하거나 완성도가 높은 모둠이 적절 (전체에 좋은 인상을 남기므로)
    • 발표 순서가 불이익이 되지 않도록, 뒤에 발표하는 모둠에게도 동일한 질의 시간을 보장

    D. 감동적인 마무리를 위한 팁¶

    1. 구체적인 에피소드를 언급하세요. "OO이가 3회차에서 이런 질문을 했었는데, 그때 저도 새로운 관점을 얻었습니다"처럼 특정 학생의 순간을 기억해주면 학생들이 진심으로 느낍니다.

    2. 진행자 자신의 배움을 공유하세요. "솔직히 저도 이 과정을 진행하면서 제 AI 활용 방식을 되돌아보게 되었습니다"처럼 진행자도 성장했음을 보여주면 대등한 관계가 형성됩니다.

    3. 미래를 열어두세요. "오늘이 끝이 아니라 시작입니다"라는 메시지는 클리셰이지만, 구체적인 다음 단계(향후 학습 방향 안내 표)와 함께 제시하면 실질적인 동기부여가 됩니다.

    4. 침묵을 두려워하지 마세요. 최종 메시지 후 2~3초의 침묵은 감동을 깊게 합니다. 바로 "자, 그럼 다음은~"으로 넘어가지 마시고, 학생들이 메시지를 음미할 시간을 주세요.

    5. 수료증이 있다면 한 명씩 이름을 불러주세요. 단체로 나눠주는 것보다 한 명씩 호명하며 건네는 것이 의미를 더합니다. (시간이 부족하면 대표 1명만 앞에서 받고 나머지는 배부)

    E. 이 회차에서 절대 하지 말 것¶

    1. 발표를 순위로 매기지 마세요 — "최우수 발표", "1등 프로젝트" 같은 순위 부여는 이 과정의 철학과 맞지 않습니다
    2. 결과물의 완성도를 칭찬하지 마세요 — "결과물이 예쁘다"보다 "문제를 이렇게 정의한 것이 흥미롭다"로 방향을 잡으세요
    3. "정답은 이것이었습니다"라고 말하지 마세요 — 10회차까지 "정답이 없다"를 유지하는 것이 일관성 있는 메시지입니다
    4. 서두르지 마세요 — 최종 회차는 여운이 중요합니다. 시간이 부족하면 포트폴리오 정리를 줄이고, 성찰과 마무리 메시지에 시간을 투자하세요
    5. 기술적 평가를 하지 마세요 — "AI를 잘 썼다/못 썼다"가 아니라 "사고의 과정이 보이는가"가 기준입니다

    부록 C: 3개 Layer 핵심 정리표¶

    학생들에게 나눠주거나 칠판에 게시할 수 있는 요약표입니다.

    +================================================================+
|                                                                |
|            AI 시대의 구조적 사고 — 3개 Layer 핵심 정리            |
|                                                                |
+================================================================+
|                                                                |
| Layer 1: 구조적 사고력 — "어떻게 생각할 것인가" (1~4회차)        |
|                                                                |
|   핵심 도구: CT 4요소                                           |
|     [1] 분해 — 큰 문제를 작은 문제로 나눈다                     |
|     [2] 패턴 인식 — 반복되는 구조를 찾는다                      |
|     [3] 추상화 — 핵심만 남기고 불필요한 것을 걸러낸다           |
|     [4] 알고리즘 설계 — 해결 절차를 단계별로 만든다             |
|                                                                |
|   핵심 메시지: "AI 없이도 생각하는 힘을 가져야 한다"             |
|                                                                |
+----------------------------------------------------------------+
|                                                                |
| Layer 2: AI 협업 설계력 — "어떻게 시킬 것인가" (5~8회차)        |
|                                                                |
|   핵심 도구:                                                    |
|     - AI 활용 3수준 (직접 요청 → 패턴 기반 → 시스템 설계)       |
|     - AI 협업 설계서 (목적 - 규칙 - 맥락)                       |
|     - 탐색적 대화 ("만들어줘"가 아니라 "생각해봐")               |
|     - 생성 장치(Harness) (결과물이 아니라 시스템을 만든다)       |
|                                                                |
|   핵심 메시지: "사고의 주도권은 내가 가지고, AI의 능력을 빌린다"  |
|                                                                |
+----------------------------------------------------------------+
|                                                                |
| Layer 3: 분야 융합 적용력 — "어디에 쓸 것인가" (9~10회차)        |
|                                                                |
|   핵심 도구:                                                    |
|     - IT + Something (기술 + 자기 분야)                         |
|     - 가치 창출 지점 분석 (반복성, 구조화 가능성, 시간 절감)     |
|     - 미니 프로젝트 (설계 → 실행 → 발표 → 회고)                |
|                                                                |
|   핵심 메시지: "기술만으로는 부족하다. 나만의 분야가 경쟁력이다"  |
|                                                                |
+================================================================+
|                                                                |
| 이 과정을 한 문장으로:                                          |
|                                                                |
|   "AI 시대에 남는 것은 구조적으로 사고하고,                      |
|    AI와 대등하게 협업하며,                                       |
|    자기 분야에서 가치를 만드는 사람이다."                         |
|                                                                |
+================================================================+

    부록 D: "6개월 후의 나에게" 편지 (시간 여유 시 추가 활동)¶
